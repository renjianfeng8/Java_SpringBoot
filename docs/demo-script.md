## 2 主剧本：买一张票（约 2 分钟）

1. 打开 `http://localhost:5173`，登录 `u1 / u1`。
2. 首页 → 点任意影片 → 「选择影院」→ 任意一家都已排片（推荐「中影华林国际影城」）。
3. 影院详情页 → 选一场 → 点「选座购票」。
4. 选 2 个相邻座位 → 提交订单。
5. 弹出支付窗 → 输入支付密码 `123456`。
6. 支付成功 → 屏幕上出现**取票码**（形如 `ABCD-EFGH`）。
7. 点顶部「取票大厅」→ 输入取票码 → 核销成功。

**讲述重点**：余额实时扣减，座位变「已售」，订单状态「待支付」→「待取票」→「已取票」。

## 3 并发剧本：两个人抢同一个座位（约 2 分钟）

1. 浏览器 A 登录 `u1`，浏览器 B（或无痕）登录 `u2`。
2. 两人**都进入同一场次的选座页**，都先不选。
3. 同时选同一个座位，然后**同时点提交**。
4. 一人成功进入支付，另一人提示「座位已售」。

**讲述重点**：后端在场次行上加锁，同场次下单串行；实测先到者 13 ms 成功、后到者 26 ms 被拒。

## 4 补充剧本（各 1 分钟，按需选）

### 4.1 超时废单
用 `s05` 买一张票，**停在支付页不付款**；5 分钟后座位自动释放、订单转「已取消」。

### 4.2 临近开演不能退
挑一场 1 小时内开演的场次买票并支付，然后去「我的订单」点「退票」→ 提示已过退票截止（映前 60 分钟）。

### 4.3 资金流水
登录任一 `s0x` → 头像 →「我的账户」：流水从充值 800 开始逐笔扣减，余额与末笔一致。

### 4.4 评论区与评分
打开《无间道》详情页 → 评论区有多条评价与点赞数；用 `s03` 登录（已评价过）再评会被拒；用当天买过票的账号可以发新评价。

### 4.5 管理端
- 首页：影院状态、影片类型分布、订单状态四态、近 7 日票房。
- 影片页：票房榜按实时汇总（《无间道》居前）。
- 影院页：11 家已审核 + 1 家待审核，可审核 `demo_pending`。
- 用户/订单/评价页：14 个用户、92 单、25 条评价。
