## 2 主剧本：买一张票（约 2 分钟）

1. 打开 `http://localhost:5173`，登录 `u1 / u1`。
2. 首页 → 点任意影片 → 「选择影院」→ 选**第一家有排片的影院**（就是演示影厅所在那家）。
3. 影院详情页 → 找到「1号演示厅」的排片 → 点「选座购票」。
4. 选 2 个相邻座位 → 提交订单。
5. 弹出支付窗 → 输入支付密码 `123456`。
6. 支付成功 → 屏幕上出现**取票码**（形如 `ABCD-EFGH`）。
7. 点顶部「取票大厅」→ 输入取票码 → 核销成功，显示凭条。

**讲述重点**：余额从 500 扣到 410，座位变「已售」，订单状态从「待支付」变「待取票」。

## 3 并发剧本：两个人抢同一个座位（约 2 分钟）

这是**最能体现实力**的一段，也是唯一需要准备两个浏览器的部分。

1. 浏览器 A 登录 `u1`，浏览器 B（或无痕窗口）登录 `u2`。
2. 两人**都进入同一个场次的选座页**，但**都不要先选**。
3. 让两人同时选 **3排3座**，然后**同时点提交**（一个人点完立刻让另一个人点）。
4. 结果：一人成功进入支付，另一人提示「座位已售」。

**讲述重点**：
- 后端在**场次行上加锁**，同场次的下单是串行的，所以不会双卖。
- **实测数据**：本地两人同时抢同一座位，先到者 13 ms 成功、后到者 26 ms 收到「座位已售」。锁等待是毫秒级，不会出现肉眼可见的卡顿。
- 前端在提交期间显示转圈 + 「正在校验座位，若有人同时选中请不要重复点击」，避免被误读成"点了没反应"。

> ✅ **已验证**：5 轮并发抢座测试中，3 个有效轮次全部「恰好一人成功」，零双卖；另 2 轮是我座位号越界（3排9座超出 8 排），不是缺陷。

## 4 补充剧本（各 1 分钟，按需选）

### 4.1 超时废单（排片 C）
1. 登录 `u1` → 排片 C → 选座 → 提交 → **不要支付**。
2. 等 5 分钟（或直接等清理任务，每 15 秒扫一次）。
3. 刷新选座页 → 刚才的座位变回「可选」。
4. 订单状态变「已取消」。

### 4.2 临近开演不能退（排片 B）
1. 登录 `u1` → 排片 B（1 小时后开演）→ 买一张票 → 支付。
2. 去「我的订单」→ 点「退票」→ 提示「已过退票截止时间（放映前 60 分钟）」。

### 4.3 资金流水（账户页）
1. 登录 `u1` → 头像 → 我的账户。
2. 看「资金流水」表：刚才的购票是一条 `购票 -90.00`，且 `变动后余额` 与当前余额一致。
3. 看「余额走势」折线图。
